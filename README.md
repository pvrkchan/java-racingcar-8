# java-racingcar-precourse

## ⚙️ 기능 구현 목록 (To Do)


1. 사용자로부터 경주할 자동차 이름들을 입력받는다.
    - [X] 입력 받기 전, 문구를 화면에 출력한다.  
        - `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`


2. 사용자로부터 받은 문자열(경주할 자동차 이름들)에 대하여 검증한다.
    - [X] 각 자동차의 이름은 영문자 5자 이하만 가능하다. 
    - [X] 각 자동차 이름은 쉼표(,)를 기준으로 구분한다.
    - [X] 경주의 특성상, 자동차 이름은 최소 2개가 입력되어야 한다.
    - [X] `* 예외처리` 문자열이 빈 문자열일 때, **IllegalArgumentException** 발생
    - [X] `* 예외처리` 문자열에 영문자와 쉼표를 제외한 것이 입력된다면 **IllegalArgumentException** 발생
    - [X] `* 예외처리` 문자열이 쉼표로 시작되거나 끝났을 때, **IllegalArgumentException** 발생
    - [X] `* 예외처리` 자동차 이름이 한 개만 주어졌을 때 **IllegalArgumentException** 발생
    - [X] `* 예외처리` 자동차 이름이 6자 이상이라면, **IllegalArgumentException** 발생
    - [X] `* 예외처리` 쉼표 사이에 빈 문자열 입력되었을 때, **IllegalArgumentException** 발생
    - [X] `* 예외처리` 중복된 이름이 입력되었을 때, **IllegalArgumentException** 발생


3. 사용자로부터 시도할 횟수를 입력받는다.
    - [X] 입력 받기 전, 문구를 화면에 출력한다.
        - `시도할 횟수는 몇 회인가요?`
    - [X] `* 예외처리`숫자가 아닌 기타 포맷이 입력될 경우, **IllegalArgumentException** 발생


4. 사용자로부터 받은 정수(시도할 횟수)에 대하여 검증한다.
    - [X] 횟수는 1 이상의 양의 정수만을 인정한다.
    - [X] 횟수는 가독성을 고려하여 최대 150번으로 인정한다.
    - [X] `* 예외처리` 0 또는 음의 정수가 입력될 경우, **IllegalArgumentException** 발생
    - [X] `* 예외처리` 151 이상의 정수가 입력될 경우, **IllegalArgumentException** 발생


5. 사용자가 입력한 경주할 자동차를 등록한다.
    - [X] 각 자동차의 위치는 0으로 초기화한다.


6. 사용자가 입력한 횟수만큼 반복하며, 자동차를 전진시키거나 정지시킨다.
    - [X] 전진하는 조건은 0 에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
    - [X] 0에서 3이 나올 경우 자동차는 정지한다.


7. 차수별로 실행 결과를 화면에 출력한다.
    - [X] 차수별로 차량 현재 위치를 출력한다. 
    - [X] 위치 출력은 `-`를 이용하여 출력한다. 2칸을 전진했다면 `--`가 될 것이다.
    - [X] 자동차 출력 순서는 사용자가 입력한 순서대로 출력한다.
        - `pobi,woni,jun`가 입력되었다면, 실행 결과도 이 순서대로 출력한다.


8. 경주를 마치고 최종 우승자를 골라낸다.
    - [X] 우승자로는 가장 많이 전진한 자동차를 선정한다.
    - [X] 우승자는 한 명 이상 선정될 수 있다.


9. 최종 우승자를 화면에 출력한다.
    - [X] 한 명일 경우 그냥 출력한다.
        - `최종 우승자 : pobi`
    - [X] 여러 명일 경우 쉼표(,)를 이용하여 구분하여 출력한다.
        - `최종 우승자 : pobi, jun`
